# N.A Nkabinde Attorneys — independent website concept

Static multi-page responsive site built on established C.O. Were style. No build step or external code dependencies.

## Deploy
- Static framework: Other; project and output root `.`, no build command.
- Local preview: `python3 -m http.server 8000` from project root, then http://localhost:8000
- After creating GitHub repo: `git push -u origin main && npx vercel --prod`
